# GPG 5 – Lebensraum Erde

Übersicht: https://hob26.github.io/GPG_5/

Jede Übung ist eine eigene Datei (`2-1.html` bis `2-9.html`).
Übung austauschen: die Platzhalter-Datei (z. B. `2-1.html`) durch die echte Übung ersetzen
(gleicher Dateiname) und in der Haupt-`index.html` bei `UEBUNGEN` den Titel
eintragen und `fertig: true` setzen.
